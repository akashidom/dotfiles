# akashidom's dotfiles

This repository contains my dotfiles for Linux. It mainly contains configuration files for various tools.

Managed with [chezmoi](https://www.chezmoi.io/).

---

# Installation

To install my dotfiles, use this command:

```bash
chezmoi init --apply https://github.com/akashidom/chezmoi
```

You need to have **chezmoi** installed to use this command.
